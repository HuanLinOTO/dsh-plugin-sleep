## 工具注册面人工对照（alpha.5 `packages/core/tools`）

ambient 影子类型（`src/types.d.ts`）不随宿主编译，typecheck 不构成安全网（J1-19 service-stand-in 同族风险），故对所用面逐项人工比对：

| 插件所用 | alpha.5 现状 | 结论 |
|---|---|---|
| `defineTool({ name, description, parameters, output:{schema,render}, execute })` | `DefineToolOptions<S,O>` 同形；DSL（`ParameterSchemaSpec` per-property `required: true`；`output.schema` 为 `ObjectValueSchemaSpec` 显式 `additionalProperties`）保留 | 兼容 |
| `exec.signal`（唯一读取的 exec 成员） | `ToolRunContext extends ToolExecution`，`signal` 仍在；新增成员均为 additive | 兼容 |
| `ctx.tools.register(def): () => void` | 同签名，仍 effect 式（fiber dispose 自动注销） | 兼容 |
| `ContentBlock` = `{ type:'text', text }` | `ContentBlockMap['text']` = `TextBlock` 仍在 | 兼容 |
| `z.object({...}).default(...)`（schemastery Config） | vendored `3.18.5-alpha.2` 同 API；单实例（版本对齐宿主） | 兼容 |

## 行动

1. peers 批量提升（主控预先完成，随本次提交）：`@deepseek-ai/dsh-tools`/`dsh-llm` `^0.2.0-rc.1`→`^0.2.1-alpha.5`，`@deepseek-ai/cordis` `^4.0.1`→`~4.0.5-alpha.2`（J1-01 修法 B）。

5. `version` 0.2.1→0.2.2。
6. 源码（`src/*.ts`）与 `cordis.patch.yml` **零改动**——所用 API 面在 alpha.5 全部兼容。
